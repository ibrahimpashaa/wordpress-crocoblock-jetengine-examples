# JetFormBuilder – Property Enquiry Form

## Overview

This example demonstrates how JetFormBuilder can be used to create a dynamic property enquiry form in WordPress.

It continues from the Property Listing system created in the previous examples and shows how users can submit enquiries for a specific property.

## Form Fields

- Name
- Email
- Phone
- Property ID
- Property Title
- Message

## Dynamic Property Data

The form can automatically capture information from the current property, including:

- Property ID
- Property title
- Property URL

This allows each enquiry to remain connected to the correct property listing.

## Form Actions

The form can be configured to:

- Send an email notification
- Save form records
- Send data to a webhook
- Trigger external automation
- Redirect users after submission

## Integration Flow

`Property Listing`

↓

`JetFormBuilder Enquiry Form`

↓

`Email / Database / Webhook / Automation`

## Tools Used

- WordPress
- Crocoblock
- JetEngine
- JetFormBuilder
- Elementor Pro
- Webhooks

## Purpose

The purpose of this example is to demonstrate how dynamic WordPress listings can be connected to user-submitted forms and external workflows using JetFormBuilder.
