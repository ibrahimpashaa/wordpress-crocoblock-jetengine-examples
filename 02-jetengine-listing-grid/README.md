# JetEngine Listing Grid – Property Listings

## Overview

This example demonstrates how to display dynamic Property data using the JetEngine Listing Grid and Elementor Pro.

It continues from the Property Custom Post Type created in Example 01 and shows how custom fields can be presented dynamically without hardcoding individual property information.

## Data Source

**Post Type:** Properties

The listing uses the custom fields created in Example 01:

| Field | Meta Key |
|---|---|
| Property Price | `property_price` |
| Location | `property_location` |
| Property Type | `property_type` |
| Bedrooms | `bedrooms` |
| Bathrooms | `bathrooms` |
| Property Size | `property_size` |

## Listing Structure

Each property listing item can dynamically display:

- Property title
- Featured image
- Property price
- Location
- Property type
- Number of bedrooms
- Number of bathrooms
- Property size
- Link to the individual property

## Tools Used

- WordPress
- JetEngine
- Elementor Pro
- JetEngine Listing Grid

## Purpose

The purpose of this example is to demonstrate how structured WordPress data can be converted into reusable dynamic listing cards using JetEngine.
