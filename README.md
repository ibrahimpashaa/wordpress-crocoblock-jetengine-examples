# WordPress Crocoblock & JetEngine Examples

A practical collection of WordPress development examples using **Crocoblock, JetEngine, Elementor Pro and custom WordPress functionality**.

This repository demonstrates approaches for building dynamic WordPress websites including custom post types, custom fields, dynamic listings, advanced queries, filters and forms.

## Technologies

- WordPress
- Crocoblock
- JetEngine
- Elementor Pro
- JetSmartFilters
- JetFormBuilder
- PHP
- JavaScript
- WordPress REST API

## Planned Examples

- Custom Post Types (CPTs)
- Custom Fields and Meta Data
- Dynamic Listing Grids
- Query Builder
- JetSmartFilters
- JetFormBuilder
- Relations between content types
- Dynamic Visibility
- Custom PHP functionality
- REST API integrations

## Purpose

The purpose of this repository is to document practical WordPress development patterns and demonstrate how Crocoblock and JetEngine can be used to build scalable, data-driven WordPress solutions.
