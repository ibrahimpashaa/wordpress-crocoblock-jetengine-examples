# JetEngine Custom Post Type – Property Listings

## Overview

This example demonstrates how JetEngine can be used to create a structured Property Listing system in WordPress using a Custom Post Type (CPT) and custom meta fields.

The property data created in this example will later be used with Elementor Pro, JetEngine Listing Grid, Query Builder and JetSmartFilters to build a complete dynamic property listing experience.

## Custom Post Type

**Post Type Name:** Properties  
**Post Type Slug:** properties

## Custom Fields

| Field | Meta Key | Type |
|---|---|---|
| Property Price | property_price | Number |
| Location | property_location | Text |
| Property Type | property_type | Select |
| Bedrooms | bedrooms | Number |
| Bathrooms | bathrooms | Number |
| Property Size | property_size | Number |
| Featured Property | featured_property | Switcher |
